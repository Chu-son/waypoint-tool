## 1. 画面構成とワークスペース

<p align="center">
  <img src="./images/main-app.png" alt="全体レイアウト" width="800"/>
</p>

アプリケーションは、高密度かつ洗練されたダークテーマ（Linear Style）で構成されており、以下の主要領域で構成されています：

| 領域 | 名称 | 役割・機能 |
|---|---|---|
| **最上部** | **カスタムタイトルバー** | アプリケーションメニュー（File / Edit / View / Help）、プロジェクト名、未保存インジケータ（`isDirty`）、パス計算ルーターメニュー、ウィンドウ操作コントロール。 |
| **左端** | **メインツールバー (ToolPanel)** | 主要ツールの切り替え（Select, Add Waypoint, Add Export Region, Measure）、および Import / Export / Settings モーダル起動ボタン。 |
| **左パネル** | **サイドパネル (Left)** | 「Waypoints」（ノード階層ツリー）、「Annotations」（ベクター図形ツリー）、「Plugins」（ジェネレーター一覧）等のタブをホスト。 |
| **中央** | **メインキャンバス (MapCanvas)** | PixiJS (WebGL) による高速レンダリング領域。背景マップ、ウェイポイント、パス、フットプリント、アノテーション等の描画と直接対話。 |
| **右パネル** | **サイドパネル (Right)** | 「Layers」（マップ＆カスタムレイヤー管理）、「Inspector」（選択要素の属性・座標・オプション編集）等のタブをホスト。 |
| **最下部** | **ステータスバー (StatusBar)** | 現在のモードバッジ、Escキー遷移先ボタン、カーソル世界座標 $(X, Y)$・極座標・ローカル座標、挿入位置、選択ノード数、全経路長、未保存バッジ＆クイック保存、マップ解像度、ズーム倍率、Fitボタン。 |

### パネルの自由ドッキングと上下分割
- **タブ切り替え / 上下分割**: 左右各パネル右上のアイコンをクリックすることで、タブ形式表示と上下分割表示を切り替えられます。
- **左右ドッキング移動**: タブヘッダーを右クリックして「Move to Opposite Panel」を選択すると、タブを反対側のパネルへ瞬時に移動できます。
- **タブの並び替え**: タブをドラッグ＆ドロップして好みの順序に並び替えられます。
- **レイアウトのリセット**: `View > Reset Window Layout` を選択すると、パネル幅や配置が初期状態へリセットされます。

## 2. プロジェクトの作成・保存・保護

### プロジェクトファイル (`.wptroj`)
本ツールは、作業状態のすべて（マップ画像のBase64データ、全Waypoint階層、アノテーション、カスタムレイヤー、ロボットフットプリント、カスタム属性スキーマ、エクスポートテンプレート、UI設定等）を単一のプロジェクトファイル（`.wptroj`）に完全内包して保存します。

| アクション | ショートカット | 説明 |
|---|---|---|
| **New Project** | `Ctrl + N` | 現在の作業をリセットし、初期状態から新しいプロジェクトを開始します。 |
| **Open Project...** | `Ctrl + O` | 保存済みの `.wptroj` ファイルを選択して読み込みます。 |
| **Save Project** | `Ctrl + S` | 現在のプロジェクトを上書き保存（未保存時はファイル選択ダイアログが開きます）。 |
| **Undo / Redo** | `Ctrl + Z` / `Ctrl + Y` | ノードの追加・移動・変形・削除などの操作履歴を元に戻す・やり直す。 |

### 未保存変更の全経路保護 (Data Protection Guard)
ユーザーの作業データを保護するため、未保存の変更（ステータスバーやタイトルバーに `Dirty` 表示）がある状態で「新規作成」「開く」「ウェルカム画面への移動」「ドラッグ＆ドロップでの別ファイル読み込み」を実行しようとすると、必ず確認ダイアログが表示され、不意のデータ消失を防止します。

## 3. マップの読み込みとレイヤー管理

<p align="center">
  <img src="./images/layers-panel.png" alt="レイヤーパネル" width="800"/>
</p>

### マップの追加
1. 右パネルの **「Layers」** タブを開きます。
2. **「Add Map」** ボタン（またはキャンバス中央のドラッグ＆ドロップエリア）から、ROS 形式の `map.yaml` を選択します（同ディレクトリに対応する `.pgm` や `.png` 画像が必要です）。
3. 読み込まれたマップがキャンバスに描画されます。

### レイヤーの操作
- **表示 / 非表示**: レイヤーカードの目のアイコンをクリックしてトグルします。
- **不透明度調整**: スライダー（0〜100%）で透過度を滑らかに変更できます。
- **重ね合わせ順序**: レイヤーカードを上下にドラッグ＆ドロップして描画順序を変更できます。
- **アクティブマップ設定**: 複数マップ存在時、基準とするアクティブマップを選択できます。

### 3色占有ハイライト表示 (Occupancy Highlight Filter)
`Settings > Appearance` で「Occupancy Highlight」を有効にすると、PixiJS GPU GLSL シェーダーによりマップ画像がリアルタイムに3色色分け表示されます：
- **赤色 (Obstacle)**: 障害物領域（占有閾値以上）
- **緑色 (Free)**: 移動可能領域（自由空間閾値以下）
- **紫色 (Unknown)**: 未知領域

### マップフィット
- `View > Fit to Map`、ステータスバー右端の **Fit** ボタン、またはマウス中ボタンのダブルクリックにより、キャンバス上の全マップが画面にぴったり収まるよう自動ズーム・センタリングされます。

### 背景地図（OpenStreetMap / 衛星画像）との重ね合わせ (Geo Base Map)
Layers タブ最上部の **Geo Base Map** カードで、実際の地図をすべてのレイヤーの最背面に表示できます（インターネット接続が必要。一度表示したタイルはキャッシュされ、オフラインでも表示されます）。

1. スイッチをオンにします。
2. **Base map** で種類を選びます：`Map (OpenStreetMap)`（道路地図）、`Satellite (Esri)`（衛星画像）、`Aerial Photo (GSI Japan)`（国土地理院の空中写真）、`Standard Map (GSI Japan)`、`Custom URL`（`{z}` `{x}` `{y}` を含むタイル URL）。切り替えても位置合わせはそのまま保たれます。
3. **World origin (0, 0) is at** に、ワールド座標の原点（ROS マップの座標 (0, 0)）が実世界のどこに当たるかを、緯度経度または UTM で入力します。
4. 重なりを見ながら **Alignment** で調整します。
   - **Offset X / Y (m)**、**Rotation (°)**（反時計回りが正）を数値入力します。
   - **Align on canvas** を押すと位置合わせモードになり、キャンバス上を**ドラッグして地図を移動**、**Shift+ドラッグで原点まわりに回転**できます（原点の位置にマーカーが表示されます）。ドラッグ中に `Esc` で開始前に戻り、もう一度 `Esc`（または **Done aligning**）で選択モードへ戻ります。中ボタンドラッグでのパンは通常どおり使えます。
   - 1 回のドラッグ、または 1 つの入力欄への入力は `Ctrl+Z` で 1 回で元に戻せます。**Reset** でオフセットと回転を 0 に戻します。
5. **Opacity** で背景地図の濃さを調整します。設定はプロジェクトファイルに保存されます。

> 地図データの提供元の利用条件に従ってください（OpenStreetMap のタイルサーバーは大量取得や商用の常時利用に制限があります）。画面右下に表示される帰属表示は消せません。

## 4. Waypoint の配置・高度な編集・階層管理

<p align="center">
  <img src="./images/waypoints-demo.png" alt="Waypoint 配置デモ" width="800"/>
</p>

### 基本配置
1. ツールバーの **「Add Waypoint」** ツール（または `P` キー）を選択します。
2. キャンバス上の任意の位置をクリックすると、新しい Waypoint が追加されます。
3. ノード先端の **Yaw 回転ハンドル** をドラッグすることで、ロボットの向き（姿勢角）を直感的に設定できます。

### 高度な直交スナップと精密数値入力
既存の Waypoint 付近で作業する際、強力なスナップ機能が自動的に作動します：

| 操作 | 動作と効果 |
|---|---|
| **マウスを既存ノードに近づける** | X軸 / Y軸 直交方向へのスナップガイド線が自動表示されます。 |
| **数値入力（例: `1.5`）+ `Enter`** | 基準ノードから指定した距離（メートル）の位置に正確にポイントを追加します。 |
| **矢印キー（`↑`, `↓`, `←`, `→`）** | 基準ノードから前後左右（0°, 90°, 180°, 270°）への軸方向を強制ロックします。 |
| **`Tab` / `Shift + Tab`** | スナップの基準となるノードを順番に切り替えます。 |

### 階層ツリー管理 (`WaypointTree`)
<p align="center">
  <img src="./images/waypoints-panel.png" alt="Waypoints パネル" width="800"/>
</p>

- **階層構造**: ノードはグループ（`group` / `manual_group`）で論理的にフォルダ分けできます。
- **ドラッグ＆ドロップ並び替え**: ツリー内でノードを自由に並び替えられます。`Shift + クリック` で不連続な複数ノードを選択し、一括でドラッグ移動（連続化配置）することも可能です。
- **挿入位置インジケーター（青いライン）**: 次に新規作成されるノードが追加される位置を視覚表示します。ツリー行をクリックすることで任意の場所に挿入先を指定できます。

### インスペクターによる数値編集
右パネル **「Inspector」** タブで、選択中ノードの詳細値を編集できます：
- **Transform**: ワールド座標（$X, Y, Z$）および姿勢（Yaw角 / クォータニオン $qx, qy, qz, qw$）。
- **アンカー設定**: ノードを右クリックして「Set as Anchor」を選択すると、基準アンカーノードからの相対座標（$dx, dy, dz, dYaw$）が表示・編集できます。
- **Transform の連続コピー (`element_paste`)**:
  インスペクターの Transform ラベル（X, Y, Z, Yaw）を右クリックしてコピー状態にし、キャンバス上の別ノードをクリックしていくことで、同じ数値を連続的に素早く適用できます。

## 5. アノテーションの作成と活用 (Vector ROI)

アノテーションは、進入禁止エリア（Keep-out Zone）、走行推奨レーン、仮想壁、目標エリアなどの**ベクター幾何メタデータ**を管理する機能です。

### 5つの幾何図形
1. **Point**: 単一の目標地点やランドマーク。
2. **OrientedPoint**: 向き情報（Yaw）を持った指定地点。
3. **Line**: 境界線、仮想壁、進入禁止ライン（実寸長さ表示可能）。
4. **Rect**: 矩形の関心領域（ROI）や進入禁止エリア（回転可能）。
5. **Circle**: 円形の防護エリアやクリアランスゾーン。

### 操作方法
1. 左パネルの **「Annotations」** タブを開き、「Add Annotation」または各サブツールを選択します。
2. キャンバス上をドラッグして図形をラバーバンド描画します。
3. 描画後は、頂点ハンドル、リサイズハンドル、回転ハンドルをドラッグしてサイズや角度を自由に変形できます。
4. 色や透過度、ラベル表示のON/OFFは右パネルの **Annotation Inspector** で調整できます。

## 6. カスタムレイヤーの作成・編集 (Raster Occupancy)

カスタムレイヤーは、Occupancy Grid（占有格子地図）のピクセルレベルでの加筆・修正を行う機能です。

### 手動ベクター描画レイヤー (`manual`)
- 直線（`Line`）、矩形（`Rect`）、円形（`Circle`）、フリーハンドブラシ（`Freehand`）を使って、マップ上に障害物（黒 / 値0）や走行可能エリア（白 / 値255）を描画できます。
- 描画した図形はベクターオブジェクトとして保持されるため、後から何度でもリサイズや移動、回転が可能です。

### プラグイン生成レイヤー (`plugin`)
- 外部プラグイン（走行可能エリア抽出やノイズ除去等）が出力した占有格子画像をレイヤーとして追加できます。

### ブレンドモードとリアルタイムプレビュー
- **Overwrite**: 上のレイヤーの値で下層を完全に塗りつぶします。
- **Merge Obstacles**: 障害物（黒ピクセル）を優先して合成します。
- **Merge Free**: 自由空間（白ピクセル）を優先して合成します。
- Rust バックエンドによる高速プレビュー（`blend_map_preview`）により、複数レイヤーの重ね合わせ結果を即座に確認できます。

## 7. ロボットフットプリント & パスルーティング

### ロボットフットプリント設定
`Settings > Robot Footprint` でロボットの外形寸法を定義します：
- **円形 (Circular)**: 半径 (m)
- **矩形 (Rectangular)**: 前後長 (Length)、左右幅 (Width)、中心オフセット
- **多角形 (Polygon)**: 頂点座標リスト $[[x, y], ...]$（ROS Nav2 標準形式テキストと相互同期）

キャンバス上でフットプリント表示を有効にすると、各 Waypoint の位置と向きに合わせてロボットの実寸フットプリント枠と進行方向インジケーターが描画されます。

### パスルーティングとコリドー帯
- **パス計算**: トップバーの **Path Router Menu** から、直線補間または組み込みの **Dijkstra 回避パス計算プラグイン** を選択できます。
- **Auto Recalculate**: 有効にすると、ノードを追加・移動するたびに障害物を自動回避する安全な経路がリアルタイムに再計算されます。
- **コリドー帯描画**: パスラインをロボットのフットプリント幅と同期させた実寸幅の半透明通過帯（コリドー）として描画し、通路の狭小箇所でロボットが壁に接触しないか視覚的に検証できます。

## 8. 実寸距離の計測 (Measurement Tool)

1. ツールバーの **「Measure」** アイコン（または `M` キー）を押します。
2. キャンバス上の任意の2点、またはノード/アノテーションの頂点をクリックします。
3. 2点間の直線距離 (m) および X軸・Y軸成分 ($dx, dy$) が HUD バッジとしてリアルタイム表示されます。
4. バナーの「Save as Annotation」をクリックすると、計測結果を寸法線アノテーション（`LineAnnotation`）として保存できます。

## 9. 条件付き書式 (Conditional Styles)

Waypoint やパス、フットプリント、アノテーションの属性値（例: 目標速度、タスク名、停止時間）に応じて、キャンバス上の表示スタイルを自動的に切り替える機能です。

### 設定手順
1. `Settings > Conditional Styles` タブを開きます。
2. **「Add Rule」** をクリックし、対象要素（Waypoint / Path / Footprint / Annotation）を選択します。
3. 条件（AND / OR グループ）を設定します（例: `options.speed >= 1.5`、`name contains "charge"`）。
4. オーバーライドするスタイルを設定します：
   - **Waypoint**: 色、塗りつぶし色、マーカー形状（Circle, Square, Diamond, Star等）、スケール
   - **Path**: 線色、実寸線幅、破線パターン（Dashed, Dotted）
   - **Footprint**: 強制表示、カスタムサイズ
5. ルールは上から順に評価され、ドラッグ＆ドロップで優先順位を変更できます。

## 10. カスタム属性の定義 (Option Schema)

Waypoint にロボット独自のカスタム属性を付加できます。

1. `Settings > Option Schema` タブを開きます。
2. **「Add Field」** をクリックし、フィールド名、表示ラベル、型（`string`, `float`, `integer`, `boolean`, `list`）、デフォルト値を設定します。
3. 「Apply Schema」を押すと、全 Waypoint の Inspector 内に専用の入力フォーム（スライダー、セレクトボックス、トグルスイッチ等）が動的に生成されます。

## 11. 自動生成プラグイン & パイプライン (Generators & Pipelines)

<p align="center">
  <img src="./images/plugins-panel.png" alt="プラグインパネル" width="800"/>
</p>

### プラグインの利用手順
1. 左パネルの **「Plugins」** タブを開き、利用したいアルゴリズム（ジグザグ走査、領域探索、障害物回避経路等）をクリックします。
2. **インタラクション入力**: プラグインが要求する入力形式（座標クリック、矩形範囲ドラッグ、既存 Waypoint / アノテーションの選択等）に従ってキャンバス上で指定します。
3. **パラメータ調整**: 右パネルの Inspector に表示されるパラメータを変更すると、キャンバス上にリアルタイムで生成プレビューが更新されます。
4. **確定**: 「Apply」ボタンを押すと、プロジェクトに正式なノードとして登録されます。

### 再生成と手動編集の競合解決 (Diff & Stash)
ジェネレーターで生成した Waypoint を手動で微調整した後、プラグインのパラメータを変更して再生成（Regenerate）しようとすると、競合解決ダイアログ（`GeneratorRegenerateConflictModal`）が表示されます：
- **Keep Modifications (Stash)**: 手動で行った座標やオプションの修正を保持したまま、新しいパラメータで再生成します。
- **Overwrite**: 手動修正を破棄し、プラグインの計算結果で完全に上書きします。
- **Cancel**: 再生成を取り消します。

### ジェネレーターの展開 (Explode)
自動生成グループを「手動グループ」にバラして、個別のノードを完全に独立した手動 Waypoint として自由編集できるようにします（※不可逆操作）。

### パイプラインレシピの実行
複数プラグインを組み合わせた高度な自動処理（例: 1. 走行可能領域抽出 → 2. 領域内探索経路生成 → 3. 障害物回避スムージング）をワンクリックで実行できます。手動で入力すべきパラメータは `PipelineSetupView` に集約されて表示されます。

### Python 仮想環境の自動セットアップ (venv)
`Settings > Plugins` 内の「Setup Python venv」から、プラグイン実行に必要な仮想環境の構築および依存 pip パッケージのインストールをワンクリックで行えます。

## 12. インポート・エクスポート & プロファイル

### Handlebars テンプレートによる自由出力
`File > Export Waypoints...`（または `Ctrl + E`）から実行します。
`Settings > Export Templates` で定義した Handlebars テンプレートにより、標準の YAML だけでなく、JSON、CSV、ROS2 Nav2 XML 形式など任意のフォーマットで出力可能です。

### テンプレートインポート
`File > Import Waypoints...` から、外部ファイルを読み込めます。テンプレート内容からカラムマッピングが自動推論（`infer_import_mapping`）されるため、CSV 等のデータも手軽に取り込めます。

### 一括エクスポートプロファイル (Export Profiles)
複数のエクスポート処理（例: ゴール地点YAML、通過点JSON、切り出しマップ画像PNG）を1つの「プロファイル」として保存し、ワンクリックで全ファイルを一括生成できます。
- 出力先ファイルの既存ファイル衝突を事前に検知し、「上書き（Overwrite）」または「自動バックアップ（Backup）」を安全に選択できます。

### マップ切り出しエクスポート
ツールバーの **「Add Export Region」** でキャンバス上に領域枠を作成し、`File > Export Maps...` から指定範囲のマップ画像のみを高解像度ラスタライズして保存できます。

## 13. Custom UI モード (ホワイトラベル & ワークフロー)

Waypoint Tool は、設定ファイル `custom-ui.config.json` を配置するだけで、現場オペレーター向けの専用ツール（ホワイトラベル製品）へと姿を変えることができます。

### 主なカスタマイズ内容
- **ブランド**: アプリ名、ウィンドウタイトル、ロゴ、About 情報の変更。
- **テーマ**: 企業のコーポレートカラーへのテーマ色変更。
- **ワークフローパネル (`WorkflowPanel`)**:
  ステップバイステップ（1. マップ選択 → 2. ロボットサイズ指定 → 3. ルート作成 → 4. 保存）のガイダンス画面を表示し、不要な複雑なツールを隠蔽。
- **標準モードとの切り替え**:
  Custom UI モード動作中も、TopMenu の `Help > Switch to Standard UI` からいつでもフル機能の標準モードと相互に行き来できます。

## 15. トラブルシューティング & FAQ

### Q. マップ画像が表示されず、キャンバスが真っ暗です。
**A.** ROS の `map.yaml` ファイル内に記載されている画像ファイルへのパス（`image:` フィールド）を確認してください。YAML ファイルと同じディレクトリに画像（`.pgm` や `.png`）が配置されている必要があります。

### Q. Python プラグインを実行するとエラーが発生します。
**A.** 
1. `Settings > General` で指定されている Python の実行パスが正しいか確認してください。
2. `Settings > Plugins` の「Setup Python venv」を開き、必須パッケージ（numpy 等）がインストールされているか確認してください。

### Q. ウィンドウのレイアウトやパネルの配置が崩れてしまいました。
**A.** 上部メニューの `View > Reset Window Layout` をクリックしてください。左右パネル幅やタブ配置がデフォルトの初期状態にリセットされます。

### Q. ジェネレーターで生成したノードの座標を個別に編集できません。
**A.** 自動生成ノード（`generator`）はアルゴリズムによって保護されています。手動で個別に編集したい場合は、ノードを右クリックして「Explode Generator」を選択し、手動グループ（`manual_group`）へ展開してください。

# ユーザーガイド (User Guide)

ROS Waypoint Tool の基本的な使い方から、高度なカスタマイズ方法までを解説します。

## 1. はじめる

### アプリの起動
実行ファイルをダブルクリックするか、ターミナルから `npm run tauri dev` で起動します。

### マップの読み込み
1. 左側のツールバーから **「Layer Panel」** ボタン（スタックアイコン）をクリックします。
2. 「Add Map」ボタンを押し、ROS 形式の `map.yaml` を選択します。
3. マップが表示されたら、マウスの **右ドラッグ** または **中ボタン** でパン移動、**ホイール** でズームが行えます。

## 2. Waypoint の操作

### ポイントの追加
1. ツールバーの **「Add Waypoint」** ツール（プラスアイコン / `P`キー）を選択します。
2. キャンバス上の任意の位置をクリックして配置します。
3. 配置された矢印の先端をドラッグすることで、ロボットの向き（Yaw）を調整できます。

### 編集 (Inspector)
1. 配置した Waypoint を選択します。
2. 右側の **Inspector パネル** で以下の編集が可能です。
   - **Transform**: X, Y 座標、および角度を数値入力で微調整。
   - **Options**: プロジェクトごとに定義されたカスタム属性（速度、停止時間など）の入力。

### 階層管理 (Hierarchy)
- 左ペインのツールツリーから Waypoint の順序をドラッグ＆ドロップで入れ替えられます。
- 複数のポイントを選択して一括削除も可能です。

## 3. プロジェクト設定とカスタマイズ (Settings)

画面左下の **歯車アイコン** から設定画面を開きます。

### 3.1 カスタム属性 (Option Schema)
「Option Schema」タブでは、Waypoint に持たせたい追加情報の定義が可能です。
- 「Add Field」で名前・型（float, string 等）・デフォルト値を指定。
- 下部の「Apply Schema」ボタンで、即座に Inspector パネルにフォームが反映されます。

### 3.2 エクスポートテンプレート
「Export Templates」タブでは、Handlebars を利用して出力形式を定義できます。
- **YAML / JSON 形式**: 標準の出力。
- **Custom 形式**: テンプレートを記述し、独自の `.csv` や `.py` 等として出力可能。

## 4. 自動生成（プラグイン）の使用

### ジェネレーターの実行
1. ツールバーの **「Generators」** メニュー、または左ペインの「Add Generator」から使用したいプラグインを選択します。
2. **インタラクション入力**: プラグインによっては、キャンバス上での操作（矩形の描画や地点のクリック）を求められます。画面の指示に従って入力してください。
3. **パラメータ調整**: 右ペインに表示されるプラグイン固有のプロパティを調整すると、キャンバス上にリアルタイムで生成プレビューが表示されます。

### SDK の更新
設定画面の「Plugins」タブから、インストール済みプラグインの SDK (`wpt_plugin.py`) が最新かどうかを確認し、ワンクリックで更新できます。

---

## トラブルシューティング
- **マップが表示されない**: `.yaml` ファイルと同じディレクトリに画像ファイル (`.pgm` 等) があるか確認してください。
- **Python プラグインが動かない**: Settings > General から 正しい Python 実行パスが設定されているか確認してください。
